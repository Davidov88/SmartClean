# SmartClean 0.4.0-preview.2

Локальная версия для диагностики и подготовки планов. Исполнение изменений пользовательских файлов отключено в ядре и интерфейсе. Техническое обслуживание собственных артефактов требует отдельной настройки. По умолчанию оно выключено.

- Сохранённые карты открываются по кликабельному пути. В истории есть страницы планов и событий, в разделах отображается своё состояние и время обновления.
- Индекс v3 хранит таблицу каталогов и смещения детей на диске. В импорте поиск родителей и счётчики тоже размещаются на диске. Старые индексы v1 и v2 остаются читаемыми.
- Хранилище сверяется по логическим размерам файлов SmartClean. При длительном задании контролируется прирост в каталогах, которые оно пишет. Резерв свободного места на томе проверяется отдельно.
- Рабочие каталоги привязаны к процессу и, в графическом режиме, к заданию. Осиротевшие артефакты с подтверждённым происхождением подпадают под правила обслуживания. Диагностика новых планов находится в реестре решений. Ранее созданные рабочие каталоги без метки автоматически не удаляются.
- Проверка опубликованного назначения выполняется под открытыми дескрипторами основного файла и дополнительных потоков. Для удаления исходника проверяются идентификатор, полный отпечаток и действующее разрешение. Пробелы фактической проверки приведены ниже.

## Проверки и границы

Исторический результат версии 0.3 — 20/20 проверок операций и 6/6 проверок политики. Для preview.2 выполнены компиляция C# и статический разбор PowerShell 5.1/XML. Функциональные проверки, графический запуск, сканирование, очистка и переносы не выполнялись.

Для включения исполнителя остаётся практическая приёмка NTFS, восстановления после прерывания и проверки свойства файла за пределами текущего контракта, включая аудит ACL и расширенные атрибуты. Поддержка exFAT для операций изменений ограничена безопасным отказом. Скорость нового индекса на больших HDD и удобство WPF при другом DPI остаются без замеров.
