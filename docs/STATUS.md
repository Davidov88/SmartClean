# SmartClean 0.3 — состояние реализации

4 ноября 2026. Windows 10 x64, Windows PowerShell 5.1 / .NET Framework, WPF. Нативный SmartClean.exe — небольшой запускатель общего PowerShell-ядра; браузер и WebView не используются.

## Реализовано

- Все семь разделов WPF: Обзор, Рост, Очистка, Дубли, Порядок и переносы, Правила, История. Задачи выполняются отдельным процессом, есть прогресс/остановка. Сканер останавливается при неожиданном модальном окне.
- Общая политика defaults + host profile, стабильный hostId, переменные путей, защищённые пути и реальные назначения junction, исключения из сканирования. Ревизия и хеш политики проверяются, конкурентные устаревшие записи отклоняются.
- Неизменяемые планы и события: отдельное подтверждение конкретного плана, срок действия, повторная проверка политики и файлов перед исполнением. Общая блокировка изменения файлов на текущую Windows-сессию/компьютер для экземпляров SmartClean.
- Очистка выбранных узких категорий через карантин. Temp — только допустимые старые файлы; свежие и распознанные временные Claude/Codex исключены. Приложения автоматически не закрываются. Повторное разрешение на 30 дней ограничено правилом/версией/точным путём, запуск остаётся ручным.
- Дубли: несколько выбранных корней, включая разные диски; размер → SHA-256; одинаковые file IDs не считаются отдельными копиями. Все копии по умолчанию сохраняются. Перед уборкой — повторный хеш и побайтное сравнение с удерживаемой открытой копией.
- Порядок: категории по расширениям, пользовательские правила в host profile, предварительная карта путей, сохранение вложенной структуры. Перенос обычных файлов/каталогов как набора файлов — тот же исполнитель.
- Копирование с проверкой SHA-256, сохранением ACL и времени изменения, отказом от перезаписи, повторной проверкой исходного файла перед удалением. Восстановление из журнала — новый согласуемый план. Безвозвратное удаление — отдельный план только для файлов карантина.
- История каждого объекта, ошибок, частичных результатов и свободного места до/после. Исторические отчёты параллельного чата импортируются как свидетельства без новых разрешений.

## Проверки

- Verify-Operations.ps1: 20 проверок ядра — дубли, hardlinks, неподтверждённые планы, источник после изменения, защита, конкурентная ревизия, инвалидирование согласий, организация, коллизии, Temp, карантин/восстановление/удаление и история.
- Verify-PolicyIntegration.ps1: 6 проверок — 100 атомарных обновлений JSON, исключения с пробелами/скобками в реальном сканере, provenance замера, точная область повторного разрешения и исполнение.
- Verify-Worker.ps1: 3 проверки реального фонового процесса — 100 найденных совпадающих файлов, 104 одновременных чтения обновляемого JSON прогресса без ошибки, явное состояние Cancelled. Итого текущий набор: 29 проверок.
- WPF startup smoke создаёт настоящий PNG окна; data binding и заполнение обзора видны на артефакте. Средство внешнего захвата окна во время дополнительной проверки вернуло `window capture timed out: timed out waiting on channel`; полный автоматический прогон кликов всех вкладок не заявляется завершённым.

## Границы первой версии

- Generic-перенос предназначен для обычных пользовательских файлов, не для установленных/работающих приложений, баз и новых app-junction миграций. Нужен отдельный app-specific сценарий; существующие миграции Claude/Playwright сохранены в свидетельствах. Автоматически менять их новым generic-переносом нельзя.
- Пустые исходные папки после файлового переноса остаются. Нет массового переименования по содержимому/AI.
- Поиск дублей может быть ограничен MaxDiscoveryFiles, план — MaxPlanFiles. Ошибки/пропуски/достижение лимита возвращаются явно. Сетевые мутации не поддерживаются, облачные placeholders не скачиваются намеренно.
- Полнота исходного WinDirStat-экспорта по-прежнему unverified. Старые карты не становятся актуальными от обновления свободного места: проверяйте дату замера.
- Автоматическое недельное расписание не установлено. Повторные сканы/сравнение доступны из окна и CLI.
- Протокол блокировки обязателен для SmartClean и следующих чатов по AGENTS.md; уже запущенные сторонние скрипты не перехватываются автоматически.

Исправленные дефекты этапа: повторная публикация progress.json через атомарное Windows-замещение с ограниченными повторами при занятости; ошибочное сообщение запускателя после нормального закрытия; экранирование закрывающих скобок в std::wregex фильтре; остановка собственного сканера при неожиданном диалоге. Новое окно нужно открыть заново, уже открытые экземпляры не подменяют обработчики событий на лету.

## Что делать пользователю

Запустить Start-SmartClean.cmd или SmartClean.exe. Для порядка/дублей выбрать фактические папки. Сначала получить план и посмотреть каждый путь/предупреждение; затем утвердить и выполнить. Для отката — История → выбрать план → Подготовить восстановление → утвердить новый план. Никогда не использовать полный диск как первый объект организации.
