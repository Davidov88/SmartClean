# Установка и работа со SmartClean 0.4.0-preview.3

SmartClean — переносимая утилита Windows с нативным окном WPF и консолью. В этой версии доступны диагностика, сохранённые замеры, поиск дублей и подготовка планов. Исполнение очистки, карантина, восстановления и переноса пользовательских файлов выключено.

## Установка на новый ПК

Нужны Windows PowerShell 5.1 и .NET Framework 4.8. Для штатной работы SmartClean не нужны Git, Python или браузер.

1. Скачайте `SmartClean-0.4.0-preview.3-portable.zip` из раздела [Releases](https://github.com/Davidov88/SmartClean/releases/tag/v0.4.0-preview.3).
2. Распакуйте весь архив в отдельную папку, куда можно записывать файлы. Папки рядом с `SmartClean.exe` нужны для запуска.
3. Запустите `Start-SmartClean.cmd`. Сканер WinDirStat 2.9.3 уже входит в архив. Для консоли запустите `Start-SmartClean-Console.cmd`.
4. Выберите отдельную папку для локального хранения результатов и лимиты. Обзор покажет доступные тома. Скан начинается после явного выбора области и запуска.

### Запуск из исходников

Скачайте исходники ветки [wpf](https://github.com/Davidov88/SmartClean/tree/wpf) или тега выпуска, распакуйте их и выполните в папке проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Tools.ps1
.\Start-SmartClean.cmd
```

`Install-Tools.ps1` загружает закреплённую версию WinDirStat с проверкой SHA-256. `Start-SmartClean.cmd` собирает WPF-запускатель, если он отсутствует.

## Основные сценарии

1. **Обзор.** Проверьте свободное место, укажите том или папку и нажмите **Новый скан**. Для первого знакомства удобна небольшая папка. После завершения откройте сохранённый замер и раскрывайте ветки по кликабельному пути.
2. **Рост.** Выберите прежний и новый замеры одной области. Таблица показывает объём «было», «стало» и изменение. Полнота обхода отображается отдельно.
3. **Дубли.** Добавьте одну или несколько папок и нажмите **Новый поиск**. Откройте группу, при необходимости примените **Только между томами**. Для фото доступен предпросмотр. **Продолжить сравнение** использует список файлов завершённого обхода. Для учёта новых файлов запустите новый поиск.
4. **Выбор копий.** Укажите сохраняемую копию в группе и снимите **Оставить** с ненужных. **Предложить отметки для выбранного тома** проверяет выбранную сохраняемую копию на другом томе и показывает объём выбора до подтверждения. **План для снятых отметок** повторно сверяет файлы. Результат поиска и предложение сами по себе не меняют файлы.
5. **Очистка, порядок и переносы.** Подготовьте план и проверьте область, предупреждения и причины пропусков. Для этой предварительной версии доступны только диагностика и подготовка.
6. **Правила и история.** Раздел правил различает защиту от изменений и исключения из обхода. В истории видны планы, события и управление хранилищем. Автоматическое обслуживание собственных технических файлов выключено по умолчанию.

Папка результата содержит локальные пути, списки файлов и диагностические данные. При установке на другой ПК начните с чистого комплекта и отдельно выберите новую папку результатов.

Сборка C#, синтаксис PowerShell 5.1 и состав архива проверены. Функциональные прогоны версии preview.3 не проводились. Подробности см. в [статусе выпуска](STATUS.md) и [плане поиска дублей](DUPLICATES-PLAN.md).
