# SmartClean — поиск дублей и медиа

Задача поиска — сократить чтение диска на больших и повторных проходах, показать группы независимых копий и помочь выбрать, какие файлы оставить. WPF и консоль используют общий сервис поиска. Снимки WinDirStat, политика и исполнитель планов сохраняют свои контракты.

## 0.4.0-preview.3

1. Поиск проходит от размера основного потока к выборке и полному отпечатку. Для файлов больше 1 MiB образец собирается из трёх участков по 64 KiB. Выборка служит только для отбрасывания несовпадений. Маленькие кандидаты сразу читаются полностью. Файлы с пустым основным потоком участвуют в поиске, включая файлы с данными только в ADS. Полный отпечаток учитывает основной и именованные потоки.
2. Кэш поиска хранит до 65 536 отпечатков в небольших файлах с пакетной записью. Ключ учитывает версию алгоритма, идентификаторы тома и файла, параметры потоков, время изменения и запись действующего журнала NTFS. Отсутствующий, обрезанный или недоступный журнал приводит к повторному чтению. Кэш не применяется при построении плана и проверке перед изменением файлов.
3. Завершённый обход записывает контрольную точку на срок до 30 дней. Продолжение работает для прежних папок и той же политики. Оно использует сохранённый список, заново сравнивает выборки и повторно использует подтверждённые отпечатки. Для новых файлов нужен новый обход. Неполный обход не заменяет последнюю пригодную контрольную точку.
4. Группы отсортированы по оценке повторного логического объёма. Постраничный просмотр работает через дисковые указатели. Межтомный фильтр сравнивает идентификаторы томов. Группа с неизвестными идентификаторами учитывается как межтомная только при наличии как минимум двух известных разных томов. Отметки сохраняются при переходах и фильтрации.
5. Можно явно выбрать сохраняемую копию. Для предложения по другому тому SmartClean перечитывает выбранную сохраняемую копию и показывает, сколько отметок изменит. План повторно проверяет отпечатки, независимость копий и действующую политику. Исполнение пользовательских файлов в preview отключено.
6. Нативный предпросмотр загружает выбранное локальное фото по запросу. Поддержаны JPEG, PNG, BMP, GIF и TIFF до 16 MiB и 24 мегапикселей. Worker передаёт в окно миниатюру до 480 пикселей. Обработка видео и поиск похожих фото остаются отдельными функциями.

## Следующий этап

- Измерить холодный поиск, повторный поиск и продолжение на SSD и HDD. Зафиксировать прочитанные байты, количество выборок и повторно использованных отпечатков, время и пик памяти. Такие прогоны пока не выполняются по текущему ограничению.
- Для похожих фото добавить отдельный режим ручного просмотра на основе dHash, сгруппированный по пропорциям. Перцептивное сходство не должно попадать в план точных дублей.
- Для видео сначала добавить метаданные и превью по запросу. Зависимости для видео сделать опциональными. Их установку не привязывать к основному запуску SmartClean.
