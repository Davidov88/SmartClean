# Исправление большого первого обхода

Симптом: 213–241 тыс. найденных файлов, пустой каталог, непонятный нулевой счётчик
хэшей, длительные запросы статистики. Работа не зависла: счётчики и текущие пути менялись.
Причины: инвентаризация и сравнение — последовательные этапы; UI каталога обновлялся
только после завершения; путь каждого элемента повторно разрешался через filesystem;
проверка исключений выполнялась для каждой строки каждого запроса; некоторые SQL-планы
читали всю таблицу случайным порядком через неподходящий индекс. Периодические
запросы могли накладываться.

Изменения:

- Пояснение этапа, прошедшее время, средняя скорость, папки, источники, heartbeat и просмотр ошибок.
- Каталог обновляется в ходе работы не чаще раза в 10 секунд; опрос статуса последовательный.
- Видимость материализуется при изменении источников/исключений. Параметризованные
  запросы и покрывающие индексы для сводки/форматов; выборка первых файлов по индексу размера.
- Нет filesystem realpath для каждого элемента: проверка папки перед обходом, ссылки
  пропускаются, нормализация строк для элементов, полный stat только для медиа Windows.
- Неизменившиеся записи обновляют только маркер прохода, без перезаписи всех индексов.
- Набор размеров/быстрых отпечатков кандидатов строится один раз на фазу, а не на каждую страницу из 200 файлов.
- Extended Windows paths для обхода, stat и хэширования. Регрессия проверена путём длиннее 260 символов.
- Отдельное окно через `SmartClean.vbs` / `Start-SmartClean.cmd`, на установленном
  Edge/Chrome. Сканер независим от окна; это оболочка веб-интерфейса, не нативный UI.

Проверки: 14 unit/integration tests, проверка синтаксиса JS. На сохранённом реальном
индексе 241 098 файлов после миграции и прогрева кэша: статус 0,179 с,
каталог из 60 файлов 0,140 с (прямые вызовы Service). Ранее в отдельных вызовах
зафиксированы 41,265 с для статуса и 13,076 с для каталога. Это отдельные наблюдения
на этом ПК; они не обещают такую задержку на любой коллекции.

28 прежних ошибок: отказы доступа служебных папок и ошибки длинных путей.
Они не означают повреждение 28 медиафайлов. История ошибок сохраняется.
Исходный проход остановлен штатной отменой; 241 098 записей сохранены.
После обновления сканирование запущено повторно с использованием индекса.
Точный курсор каталога ещё не сохраняется — обход повторяется, сохранённые
метаданные/хэши не пересчитываются без изменения файлов.
